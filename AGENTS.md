# Repository instructions

## Keep workflow notes current

The user maintains a learning guide at `multi-agent-orchestration/WORKFLOW_ORCHESTRATION.md`.

- Whenever editing or importing changes to `multi-agent-orchestration` (including GitHub pulls and upstream merges), review the guide against the resulting code and README before finishing.
- Update affected explanations, diagrams, commands, scenario outcomes, service responsibilities, and recovery behavior in the same task. Preserve the guide and this instruction when resolving merges.
- Record the review date and a brief description in the guide's maintenance section. If a reviewed change does not affect the workflow, record that no workflow change was needed rather than inventing one.
- Verify documented commands against the implementation. Distinguish fixture runs from live model calls, and case readiness from human approval and refund execution.
- Report whether the guide was updated or reviewed when completing relevant work.

This is an instruction for assistants working in this repository, not a background watcher. Changes made outside such a session still require a documentation review.
