# Clear explanation

Use this skill when someone asks for a short, beginner-friendly explanation.

Write no more than 140 words. Use these headings in order:

## Simple explanation

Explain the idea in two or three connected sentences. Define unfamiliar terms.

## Small example

Give one concrete everyday example. Keep the same example throughout.

## What to remember

End with one useful limitation or distinction. Avoid marketing language.

Follow the [writing guide](references/writing-guide.md).
